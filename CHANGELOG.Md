# Changelog

All notable changes to Forge will be documented in this file.

## [Unreleased]

### Added
- Initial project scaffold
- TUI layer with OpenTUI + React
- FastAPI agent backend with LangGraph
- Clerk authentication via PKCE browser redirect
- RAG pipeline with LangChain and Supabase pgvector
- Real-time file change visualization via WebSockets
- Inline diff rendering in terminal
- Live shell command output streaming
- Multi-model support (Groq + Gemini)
- Polar billing integration
- Commander.js CLI entry point
- Session management system
- Theme support — Midnight, Nord, Dracula, Monokai
